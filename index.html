JavaScript - Música en el cuestionario.

En esta actividad vas a incorporar música a al cuestionario personalizado utilizando HTML y JavaScript. La música deberá cambiar según el momento del cuestionario y según el puntaje obtenido al finalizarlo.

Requisitos técnicos.

  1. Incorporar los archivos de audio al proyecto.

  2. Utilizar un elemento audio para reproducir las canciones.

  3. Seleccionar el elemento audio mediante JavaScript utilizando su id.

  4. Iniciar la música al pasar 500 ms.

  5. Reproducir una canción diferente durante las preguntas.

  6. Al finalizar el cuestionario, reproducir una canción diferente según el punta obtenido:

    • Mayor a 7 puntos.
    • Entre 4 y 7 puntos.
    • Menor a 4 puntos.


Estructura del proyecto.

Organice los archivos del proyecto de la siguiente manera: 

Apellido_Nombre/
├── index.html
├── cuestionario.html
├── final.html
├── style.css
├── main.js
└── audios/
    ├── inicio.mp3
    ├── preguntas.mp3
    ├── mayor7.mp3
    ├── entre4y7.mp3
    └── menor4.mp3


Ayudas

setTimeout()

La función setTimeout() permite ejecutar una acción después de un tiempo determinado. El tiempo se expresa en milisegundos.

Código de ejemplo: 

setTimeout(function(){
    console.log("Pasaron 500 milisegundos");
},500);

⚠️Importante⚠️

El navegador puede bloquear la reproducción con sonido si todavía no hubo interacción del usuario. Por eso, para que funcione de forma confiable en todos los navegadores, la reproducción automática puede requerir que el usuario haya interactuado previamente con la página.



Etiqueta <audio>.

La etiqueta <audio> permite incorporar un archivo de sonido al documento HTML. 

    <audio id="musica"></audio>

Seleccionar el audio mediante JavaScript.

Una vez creado el elemento <audio>, podemos seleccionarlo desde JavaScript utilizando su id y getElementById(). 

     let musica = document.getElementById("musica");

De esta manera, la variable musica hace referencia al elemento <audio> y podemos utilizarla para controlar la reproducción, cambiar la canción, modificar el volument, etc.


src.

La proiedad src permite indicar qué archivo de audio queremos reproducir. 

     musica.src = "audios/inicio.mp3"

play()

La función play() comienza la reproducción del audio. 

    musica.play();

pause()

La función pause() permite detener temporalmente la reproducción. 

 musica.pause();
